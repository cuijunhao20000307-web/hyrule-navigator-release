## 安装 Switch 端

1. 完全关闭 Switch，把 SD 卡连接电脑。
2. 解压成品包。
3. 将 `Switch端/HyruleBridgeUltra-0.6.0-ConfirmedTeleport-SD.zip` 解压到 SD 卡根目录并选择合并。
4. 确认文件位于 `SD:/switch/.overlays/HyruleBridgeUltra.ovl`。
5. 删除或覆盖同名旧版，只保留一个 `HyruleBridgeUltra.ovl`。
6. 安全弹出 SD 卡，插回 Switch 后正常开机。

本版传送功能需要 0.6.0 插件，只替换电脑端文件无法获得传送功能。

## 启动电脑端

先安装 Node.js 22 或更高版本。

- macOS：双击 `电脑端/启动电脑端.command`
- Windows：双击 `电脑端/启动电脑端-Windows.bat`
- 当前电脑网址：`http://localhost:3000`
- 手机／平板网址：`http://电脑局域网IP:3000`

每位用户都在自己的电脑上运行服务，因此局域网 IP 不会与发布者相同。电脑、手机和 Switch 必须连接同一个普通 Wi-Fi；关闭 VPN，并避免使用访客网络。

## 连接 Switch

1. 启动旷野之息并进入可以控制林克的实际存档。
2. 打开 Tesla 菜单，启动“海拉鲁导航”。
3. 在网页右上角输入 Switch 当前 IP，点击“连接”。
4. 等待网页显示坐标同步状态。

不需要 FTP，网页会直接连接 `http://Switch-IP:37890`。

## 实验传送

1. 在网页选择一个神庙、塔或附近地表。
2. 点击“发送到 Switch”。
3. 打开 Tesla → 海拉鲁导航 → 实验传送。
4. 核对坐标，选择“确认传送”并按 A。

安全限制：

- 测试前先在游戏内正常保存。
- 单次水平距离最多 500 米，高度变化最多 350 米。
- 超过距离时使用附近陆地作为中继点。
- 不要选择水面、桥梁、建筑、洞穴、室内或悬空结构。
- 不要在读档、过场、攀爬、游泳、骑乘或林克不可控时确认。
- 传送时关闭 Edizon、其他金手指界面及会重新附加 dmnt 的工具。
- 这是实验功能，仍可能出现跌落、卡住或游戏崩溃。

## 正常关闭

1. 确认没有待处理或执行中的传送。
2. 在网页点击“断开”。
3. 在 Tesla 插件中选择“停止服务并退出”。
4. 再关闭游戏或关机。

手机停止请求持续 15 秒或游戏关闭 8 秒后，插件也会自动停止网络服务。

## 常见问题

- 手机打不开：确认网址包含 `http://` 和 `:3000`，并检查同一 Wi-Fi、防火墙、VPN 和访客网络隔离。
- 主机未连接：重新查看 Switch IP，并确认插件已启动。
- 提示进入存档：必须进入能控制林克的实际游戏画面。
- Tesla 中没有插件：检查路径 `SD:/switch/.overlays/HyruleBridgeUltra.ovl`，并删除重复旧版。
- 目标超过 500 米：选择更近的中继点。
- 林克当前不可控：站在普通地面，退出读档、过场或特殊动作后重试。
